# 口播与 Q&A

## 1 分钟口播

《密码记忆替身》是一个不保存密码的账号身份关系记忆 Agent。很多账号找回失败，不是因为用户一定没有密码，而是忘了当初绑定了哪个手机号、邮箱、第三方登录、旧设备或恢复路径。我们的系统只保存脱敏线索和位置提示，不保存密码、验证码、恢复码正文、MFA secret、token 或第三方凭据。Demo 展示了真实后端驱动的工作台：查看虚构账号线索、生成本人账号找回计划、运行安全体检、检查手机号和邮箱迁移影响、导入 OCR 摘要，并对绕过验证等危险输入返回安全拒绝。

## 评委 Q&A

### 这和密码管理器有什么不同？

密码管理器保存和填充密钥；本项目保存的是账号身份关系线索，例如“这个账号可能用微信登录、绑定了某个脱敏手机号、恢复码位置在纸质笔记本”。它用于安全回忆和官方找回路径规划，不用于登录代填。

### 为什么不保存恢复码正文？

恢复码正文等同于高价值凭据。系统只允许保存位置提示，例如“纸质笔记本第 3 页”，避免数据库或日志泄露后直接造成账号接管。

### 如何证明安全边界有效？

后端有 privacy guard，危险输入会返回 `safety_blocked`。测试覆盖敏感输入拒绝，前端 Demo 也展示拒绝结果，不把它包装成普通失败。

### Demo 数据从哪里来？

Demo 使用固定虚构账号。部署时可以设置 `DEMO_SEED_ON_EMPTY=true`，后端在空存储启动时自动写入虚构数据。

### 如果后端不可用，前端会怎样？

前端显示“连接失败”和后端不可用错误；账号为空时显示“暂无账号线索”。Demo 不会伪造成功数据。

### 下一步最值得做什么？

接入真实 OCR 摘要和官方恢复指南 RAG，同时增加本地加密备份和更细的多设备迁移提醒。
